# Frontend de la Web del proyecto 

Panel de control web en modo oscuro titulado «Sistema de acceso vehicular seguro», mostrando el estado «Sistema seguro» y métricas de radiofrecuencia (Contador 0x3F2A, modulación 2-FSK activa, 2 ataques rechazados) junto con registros de tramas recibidas en 2-FSK y ASK/OOK.
